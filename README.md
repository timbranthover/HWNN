# A Horse With No Name

A quiet pixel desert to wander with a little horse. There's no way to lose. Wander through endless named regions (dunes, scrub, red rock, Joshua woods, wildflower meadows, white sands and cinder fields). Run with a herd of wild horses, race the train, read letters from M. in lonely mailboxes, take postcards, and follow the nine humming stones to remember the horse's name.

It's a plain static site with no build step: `index.html`, `game.js` and images. It deploys on Vercel with the **Other** preset, root `./`, no build command and no output directory.

Controls: drag or tap to wander (arrow keys or WASD on desktop), keep going to speed up, Space to interact, H to whinny, J journal, M map, P postcard.
