# A Horse With No Name

A quiet pixel desert to wander with a little horse. No way to lose. Collect plants, birds, rocks and things in the journal, follow the nine humming stones, and remember the horse's name.

Plain static site, no build step: `index.html` + `game.js` + images. Deploys on Vercel with the **Other** preset, root `./`, no build command, no output directory.

Controls: drag or tap to wander (arrow keys / WASD on desktop), keep going to speed up, Space to rest or drink, H to whinny, J for the journal.
